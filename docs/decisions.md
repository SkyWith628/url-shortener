# 결정 로그

## 2026-11-13 ECS는 단일 태스크에 컨테이너 3개
- 결정: frontend·backend·db를 한 Fargate 태스크에 넣고 127.0.0.1로 통신한다.
- 대안: 서비스 3개 + Service Connect, DB는 RDS.
- 이유: 마감까지 이틀이고 과제 요구가 "컨테이너 3개"다. 서비스 디스커버리와 ALB 설정을 줄인다.
- 리스크: 태스크가 다시 뜨면 DB 데이터와 퍼블릭 IP가 바뀐다. 계층별 독립 확장이 안 된다.

## 2026-11-13 스키마는 백엔드가 시작할 때 만든다
- 결정: `CREATE TABLE IF NOT EXISTS`를 백엔드 lifespan에서 실행한다.
- 대안: MySQL 컨테이너에 init.sql 마운트.
- 이유: Fargate에서는 호스트 파일을 마운트할 수 없어, DB를 공식 이미지 그대로 쓰려면 앱이 만들어야 한다.

## 2026-11-13 코드 중복은 UNIQUE 제약 + 재시도로 막는다
- 결정: 난수 6자(62^6 ≈ 568억)를 넣어 보고, 중복 오류(1062)면 새 코드로 다시 시도한다.
- 대안: 삽입 전 조회, auto increment id의 base62 인코딩.
- 이유: 조회 후 삽입은 동시 요청에서 경쟁이 생긴다. id 인코딩은 링크 수와 다음 코드를 추측할 수 있다.
- 메모: `code` 컬럼은 `ascii_bin`. 기본 콜레이션은 대소문자를 구분하지 않아 코드 공간이 줄고 조회가 모호해진다.

## 2026-11-13 리다이렉트는 302 + no-store
- 결정: 301 대신 302를 쓴다.
- 이유: 301은 브라우저가 캐시해 두 번째 클릭부터 서버에 오지 않아 집계가 빠진다.

## 2026-11-15 이미지 저장소는 Docker Hub, 배포는 실습 계정 콘솔
- 결정: 이미지는 Docker Hub 공개 저장소에 두고, ECS는 학교 실습 계정의 웹 콘솔에서 "새 태스크 실행"으로 올린다.
- 대안: 수업과 같은 ECR + AWS CLI, 개인 AWS 계정.
- 이유: 실습 계정은 웹 콘솔 로그인만 되고 제공된 액세스 키는 거부된다. Docker Hub 이미지는 CLI 없이 콘솔만으로 배포할 수 있다.
- 메모: 실행 역할에 로그 그룹 생성 권한이 없어 개정 2에서 `logConfiguration`을 뺐다. 배포본은 CloudWatch 로그가 없다.
